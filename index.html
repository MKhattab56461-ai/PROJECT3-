CSS Font Size: px vs pt vs em vs rem

The core difference is who they are relative to. px and pt are absolute. em and rem are relative.

UnitStands ForTypeRelative ToUse For Web?
pxPixelsAbsoluteScreen pixel (1px = 1 dot on screen)Okay, but not accessible for fonts
ptPointsAbsolutePhysical print size (1pt = 1/72 inch)❌ Avoid on web
emEmRelativeParent element's font-sizeGood for padding/margins that scale with text
remRoot EmRelativeRoot (html) font-size (default 16px)✅ Best for font-size

1. px - Pixel

Fixed size. Doesn't care about parent or user settings.

font-size: 16px → Exactly 16px
font-size: 24px → Exactly 24px

Problem: If user sets browser to large text for accessibility, px won't fully respect it.

2. pt - Point

For PRINT, not screens. 12pt = 1/6 inch.

font-size: 12pt ≈ 16px on screen
font-size: 18pt ≈ 24px on screen

Problem: Browsers have to guess how big an inch is on your screen. Different screens = different results.

3. em - Relative to PARENT

This is where it gets tricky. It multiplies.

Parent: 20px
Child: 1.5em = 20px * 1.5 = 30px
Child: 2em = 20px * 2 = 40px

Compounding trap: If you nest em inside em, it keeps multiplying! 1.5em inside 1.5em = 2.25x

4. rem - Relative to ROOT

Always relative to html tag. No compounding.

Assuming root = 16px (default)

font-size: 1rem = 16px
font-size: 1.5rem = 24px
font-size: 2rem = 32px

Best: Predictable, respects user settings, no nesting bug.

The Compounding Problem (Why rem > em for fonts)

em compounds:
Level 1: 1.2em (19.2px)
Level 2: 1.2em (23px)
Level 3: 1.2em (27.6px) - Getting huge!
rem stays consistent:
Level 1: 1.2rem (19.2px)
Level 2: 1.2rem (19.2px)
Level 3: 1.2rem (19.2px) - Same!

TL;DR - What should you use in 2026?

  • rem for all font-sizes → Accessible, predictable. 1rem = 16px by default. Use 1rem, 1.125rem, 1.25rem, 1.5rem etc.
  • em for padding/margin/gap inside components → e.g. padding: 0.5em 1em; will scale perfectly if the button's font-size changes.
  • px for borders, shadows, tiny details → border: 1px solid should stay 1px.
  • pt → Never for screen. Only use inside @media print { } if you are making a print stylesheet.

Pro tip: Set html { font-size: 100%; } (which is 16px) and then design everything in rem. If a user needs larger text, everything scales automatically.
